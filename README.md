# rc-frame-performance-screening
Desktop application and trained models for predicting the TBEC 2018 performance level of existing RC frames without structural analysis.

The EBM model (`ebm_BASE+A2_s42.pkl`) exceeds the GitHub file size limit; download it from Releases and place it in `app/assets/models/`.

To run the application: `pip install -r app/requirements.txt`, then `python app/app.py`.
